# 4_서면작성 매뉴얼

작업 지침은 `4_서면작성/CLAUDE.md`, 문체·구성 규칙은 `4_서면작성/skills/노동서면작성/SKILL.md` 에 있다. 이 파일은 손을 어떻게 움직이는지만 적는다.

## Claude Code 켜기

```powershell
cd "$env:OneDrive\노동사건자동화"
claude
```

폴더로 들어가지 말고 **루트에서** 슬래시 명령어로 시작한다. 명령어가 `4_서면작성/CLAUDE.md` 를 읽어 지침을 적용한다.

---

## 새 사건 시작

1. `4_서면작성/사건/_템플릿` 복사 → `4_서면작성/사건/{사건명}` 으로 만들어줘. (터미널 입력)
2. 탐색기에서 `4_서면작성/사건/{사건명}/라운드1/우리증거/` 에 자료 넣기
3. `/증거정리 {사건명} 라운드1`
4. `/서면 {사건명}`
5. (선택) `서면_프레임.docx` 가 `라운드1/출력/` 에 있으면 `/서면` 이 `({의뢰인명}) {서면명}_초안.docx` 까지 만든다(`4_서면작성/CLAUDE.md` 3-1절). 프레임을 나중에 넣었으면 `/서면` 을 다시 실행하거나 병합을 요청한다. 폴더에 넣기만 해서는 병합되지 않는다.

---

## 공방 (라운드 추가)

1. `4_서면작성/사건/{사건명}/라운드1` 복사 → `라운드2` 로 만들어줘. (터미널 입력)
2. 탐색기에서 `라운드2/상대증거/` 에 상대 서면·증거 넣기
3. 탐색기에서 `라운드2/우리증거/` 에 우리 추가 증거 넣기
4. `/증거정리 {사건명} 라운드2`
5. `/서면 {사건명} 라운드2`  (상대 서면이 있으면 반박 구성이 자동으로 켜진다)
6. (선택) `서면_프레임.docx` 가 `라운드2/출력/` 에 있으면 `/서면` 이 `({의뢰인명}) {서면명}_초안.docx` 까지 만든다. 프레임을 나중에 넣었으면 `/서면` 을 다시 실행하거나 병합을 요청한다.

---

## 슬래시 명령어

| 명령어 | 하는 일 |
|---|---|
| `/서면 {사건명}` | 최초 서면 생성 |
| `/증거정리 {사건명} 라운드N` | 증거 정리 및 호증번호 부여 |
| `/문체검증 {파일}` | 완성된 초안을 문체 규칙으로 실측 채점 |

사건명만 적으면 `4_서면작성/사건/{사건명}` 으로 읽는다.

---

## 행정소송 사건

폴더 구조는 일반 사건에 `노동위원회_기록/` 이 붙는다.

```
4_서면작성/사건/{사건명}_행정소송/
├── 노동위원회_기록/
│   ├── 우리서면/     ← 노동위 이유서·답변서 (서면+증거 합본도 가능)
│   ├── 상대서면/     ← 상대방 서면 (서면+증거 합본도 가능)
│   └── 증거/         ← 노동위 단계 증거 (별도 파일인 경우)
├── 증거관리/
└── 라운드1/
    ├── 우리증거/
    ├── 상대증거/
    ├── 참고자료/     ← 호증이 아닌 판결문·서면 등(있는 경우)
    ├── 발췌/
    ├── 작업/
    └── 출력/
```

1. `_템플릿` 복사 → `4_서면작성/사건/{사건명}_행정소송`
2. `노동위원회_기록/` 에 노동위 단계 서면·증거 넣기
3. `라운드1/상대증거/` 에 행정소송 상대방 준비서면 넣기
4. `/증거정리 {사건명}_행정소송 라운드1`
5. `/서면 {사건명}_행정소송`  (노동위원회_기록/ 이 있으면 기록 추출이 자동으로 켜진다)

## 녹음이 있는 경우

녹취는 `5_녹취록` 폴더가 맡는다. `5_녹취록/사건/{사건폴더}/원본/` 에 음성파일을 넣고 `/녹취` 를 실행한다. 자세한 절차는 `5_녹취록/CLAUDE.md` 를 본다.

정식 모드로 만든 `녹취서_*.md` 를 증거로 쓰려면 `4_서면작성/사건/{사건명}/라운드N/우리증거/` 로 옮긴 뒤 `/증거정리` 를 실행한다. 간이 모드의 `녹취록_*.md` 는 내용 확인용(헤더 빈칸, 화자 추정 표기)이므로 증거로 옮기지 않는다(`.claude/commands/녹취.md`).
