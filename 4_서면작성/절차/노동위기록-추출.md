# 노동위원회 기록 추출 절차

사건 폴더에 `노동위원회_기록/` 이 있을 때 `/서면` 이 이 절차를 먼저 적용한다.
노동위 단계 주장·증거를 소송 단계로 옮기는 입력 처리이지 별도의 서면 종류가 아니다.

다음 절차를 순서대로 실행해줘:

1. 사용자가 지정한 경로(예: 4_서면작성/사건/{사건명}/)를 확인하고
   노동위원회_기록/우리서면/ 폴더의 이유서·답변서를 모두 읽어줘.

   [합본 파일 처리]
   - 서면과 증거가 한 PDF에 합본된 경우:
     내용을 읽어서 서면 부분(주장·논거)과 증거 부분을 구분해줘.
     서면 부분 → 주장·논거 추출 목적으로만 활용
     증거 부분 → 증거관리/우리호증목록.md 에 등록
                 (파일명 뒤에 (합본) 표시, 페이지 범위 기록)
   - 서면과 증거가 별도 파일인 경우: 각각 처리

   이 서면들은 증거로 사용하지 않고 주장·논거 추출 목적으로만 활용해줘.
   추출한 주장을 작업/노동위_우리주장.md 로 정리해줘:
   - 실체적 주장 목록 (징계사유 부존재, 인과관계 등)
   - 절차적 주장 목록 (징계절차 하자 등)
   - 양정 관련 주장 목록
   - 각 주장별 근거 증거 호증번호

2. 노동위원회_기록/상대서면/ 폴더의 서면을 읽어서
   작업/노동위_상대주장.md 로 상대방 주장 목록을 정리해줘.

   [합본 파일 처리]
   - 서면과 증거가 한 PDF에 합본된 경우:
     서면 부분 → 상대방 주장 추출
     증거 부분 → 증거관리/상대호증목록.md 에 등록
                 (파일명 뒤에 (합본) 표시, 페이지 범위 기록)
   - 서면과 증거가 별도 파일인 경우: 각각 처리

3. 노동위원회_기록/증거/ 폴더의 증거자료를 읽어서
   증거관리/우리호증목록.md 에 반영되지 않은 것이 있으면
   호증번호를 부여하고 목록에 추가해줘.

4. 라운드N/상대증거/ 폴더에 행정소송 상대방 준비서면이 있는 경우
   상대방 준비서면을 분석해서 작업/상대주장분석.md 로 정리해줘:
   가. 상대방 주장 중 노동위 단계에서 이미 우리가 반박한 것
       → 기존 주장 재활용 가능 표시
   나. 상대방 주장 중 행정소송에서 새로 제기된 것
       → 신규 반박 필요 표시
   다. 반박에 추가 사실관계나 증거가 필요한 경우
       → [반박 보완 필요] 태그로 표시

5. 아래 구조로 행정소송 준비서면 초안을 작성하고
   라운드N/출력/서면초안.md 로 저장해줘:

   가. 상대방 준비서면의 주장 순서대로 항목별 반박
       (노동위 단계 기존 주장 재활용 + 신규 반박 추가)
   나. 노동위 단계 우리 주장 중 아직 행정소송 서면에 반영되지 않은 것
       추가 주장으로 편입
   다. [반박 보완 필요] 항목은 목차와 현재 가능한 반박까지만 작성하고
       이하 내용 보완 필요 표시 후 다음 항목으로 진행

   "- 다 음 -" 이후부터 입증방법까지만 작성하고
   표지·날짜·대리인·수신처 블록은 만들지 마.
   4_서면작성/skills/노동서면작성/SKILL.md 와 그 references/ 의 모든 파일을 읽고 형식 규칙 적용.

6. 초안 작성 후 하단에 아래 세 가지를 별도로 제시해줘:
   ① [확인 필요 사항] 목록
   ② ⚠️ [취약 논리 및 보완 방향]
   ③ 📎 [추가 확보 필요 증거] 목록

7. 초안 작성 전에 프레임의 목차·당사자를 확인하고 그대로 따른다. 프레임이 있으면 `공통/문서변환.md`를 읽고 DOCX를 생성한다. 프레임이 없으면 MD를 제공하고 필요한 프레임 위치를 안내한다.
