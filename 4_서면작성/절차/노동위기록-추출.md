# 노동위원회 기록 추출 절차

사건 폴더에 `노동위원회_기록/` 이 있을 때 `/서면` 이 이 절차를 함께 적용한다.
노동위 단계 주장·증거를 소송 단계로 옮기는 입력 처리이지 별도의 서면 종류가 아니다.
서면 종류는 프레임 표지가 정한다. 폴더 이름이 '행정소송'이어도 프레임이 항소이유서이면 항소이유서를 쓴다.

**이 파일은 독립 명령어가 아니다.** 순서는 `.claude/commands/서면.md` 를 따르고, 아래 각 항목은
머리에 적은 서면.md 단계에서 덧붙여 적용한다. 추출(1·2항)은 서면.md 2단계 읽기 직후, 초안을 쓰기 전에 한다.
다음은 서면.md 가 맡으므로 여기서 따로 하지 않는다.

- 대상 라운드 확인(1단계)
- 서면 종류·프레임 목차·당사자·제출처 확인(3·3-1단계). 초안을 쓰기 전에 한다.
- 증거정리(4단계). 초안을 쓰기 전에 AI 가 이 작업 안에서 직접 한다(`4_서면작성/CLAUDE.md` 2절).
- 금액 계산(5-1단계). 금액은 `/손배계산` 을 거쳐 옮기고 직접 계산하지 않는다.
- 출력 범위("- 다 음 -" 이후부터 입증방법까지, 7단계), 하단 세 목록(8단계), DOCX 생성(9단계)

1. [서면 2단계 직후] 노동위원회_기록/우리서면/ 폴더의 이유서·답변서를 모두 읽는다.

   [합본 파일 처리]
   - 서면과 증거가 한 PDF에 합본된 경우:
     내용을 읽어서 서면 부분(주장·논거)과 증거 부분을 구분한다.
     서면 부분 → 주장·논거 추출 목적으로만 활용
     증거 부분 → 증거관리/우리호증목록.md 에 등록
                 (파일명 뒤에 (합본) 표시, 페이지 범위 기록. 등록은 3항대로 서면 4단계에서 한다)
   - 서면과 증거가 별도 파일인 경우: 각각 처리

   이 서면들은 증거로 사용하지 않고 주장·논거 추출 목적으로만 활용한다.
   추출한 주장을 작업/노동위_우리주장.md 로 정리한다:
   - 실체적 주장 목록 (징계사유 부존재, 인과관계 등)
   - 절차적 주장 목록 (징계절차 하자 등)
   - 양정 관련 주장 목록
   - 각 주장별 근거 증거 호증번호

2. [서면 2단계 직후] 노동위원회_기록/상대서면/ 폴더의 서면을 읽어서
   작업/노동위_상대주장.md 로 상대방 주장 목록을 정리한다.

   [합본 파일 처리]
   - 서면과 증거가 한 PDF에 합본된 경우:
     서면 부분 → 상대방 주장 추출
     증거 부분 → 증거관리/상대호증목록.md 에 등록
                 (파일명 뒤에 (합본) 표시, 페이지 범위 기록. 등록은 3항대로 서면 4단계에서 한다)
   - 서면과 증거가 별도 파일인 경우: 각각 처리

3. [서면 4단계] 노동위원회_기록/증거/ 폴더의 증거자료와 1·2항의 합본 증거 부분 가운데
   증거관리/ 의 호증목록에 반영되지 않은 것이 있으면, 서면 4단계의 증거정리에서 함께
   호증번호를 부여하고 목록에 추가한다. 합본의 경계와 편철은 `.claude/commands/증거정리.md` 의
   특수 케이스(합본 PDF)와 '호증 경계 확정과 편철 검증'을 따른다.

4. [서면 6단계] 라운드N/상대증거/ 폴더에 상대방 서면이 있으면 서면 6단계의
   작업/상대주장분석.md 에 아래 표시를 덧붙인다:
   가. 상대방 주장 중 노동위 단계에서 이미 우리가 반박한 것
       → 기존 주장 재활용 가능 표시
   나. 상대방 주장 중 이번 소송 단계에서 새로 제기된 것
       → 신규 반박 필요 표시
   다. 반박에 추가 사실관계나 증거가 필요한 경우
       → [반박 보완 필요] 태그로 표시
       (작업 파일의 표시이다. 초안 본문에는 옮기지 않고 5항 다.에 따라 하단 목록에 적는다)

5. [서면 7단계] 초안(프레임 표지가 정한 서면)을 쓸 때 아래 구성을 더한다.

   가. 상대방 서면이 있으면 그 주장 순서대로 항목별로 반박한다
       (노동위 단계 기존 주장 재활용 + 신규 반박 추가). 구성은 `4_서면작성/절차/반박-구성.md` 3항을 따른다.
   나. 노동위 단계 우리 주장 중 아직 이번 소송 서면에 반영되지 않은 것을
       추가 주장으로 편입한다.
   다. 반박에 자료가 모자란 항목은 본문에 목차와 현재 가능한 반박까지만 쓰고,
       보완할 내용은 하단 목록에 목차 번호와 함께 적은 뒤 다음 항목으로 진행한다
       (서면.md 7·8단계, `공통/운영.md` '보완 메모'). 본문에는 대괄호 표시를 남기지 않는다.
