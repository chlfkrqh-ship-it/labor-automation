## 2. 본문 글자 서식

| 항목 | 값 |
|------|----|
| 폰트 (한글 EastAsia) | **바탕체** |
| 폰트 (영문 ASCII / hAnsi) | Times New Roman |
| 글자 크기 | **12 pt** |
| 장평 (w:w, 가로 비율) | **미설정 = 100%** (Word 기본값) |
| 자간 (w:spacing) | **미설정 = 0 pt** (Word 기본값) |

> 장평·자간은 스타일에서 명시적으로 지정되지 않았으며, Word 기본값(장평 100%, 자간 0pt)이 적용됨.
> 단, 표지 하단 "귀중" 스타일(`표지_하단_법원`)에만 자간 -0.7pt가 별도 지정되어 있음.

## 3. 줄간격 및 문단 여백

| 항목 | 값 |
|------|----|
| 줄간격 | **1.5배** (w:line=360, w:lineRule=auto) |
| 문단 앞 간격 (space before) | 0 pt |
| 문단 뒤 간격 (space after) | **0 pt** |

> docDefaults에는 줄간격 1.15배(line=276), 문단 뒤 200twip(≈0.35cm)가 설정되어 있으나,
> Normal 스타일(styleId=a4)에서 줄간격 1.5배·문단뒤 0pt로 명시적으로 덮어씀.
> 모든 본문 스타일은 Normal을 상속하므로 실제 적용값은 **1.5배 / 0pt**.

| 항목 | 값 |

## 6. 꼬리말 (Footer)

| 항목 | 값 |
|------|----|
| 위치 (정렬) | **오른쪽 정렬** (w:jc=right) |
| 페이지 번호 형식 | **아라비아 숫자** (PAGE 필드코드) |
| 폰트 (한글 / 영문) | **나눔명조** |
| 크기 | 스타일(af4) 상속값 (명시 없음) |
| 이미지 | **있음** (rId1 — 페이지 번호 주변 장식 이미지로 추정) |
| 빈 단락 | 페이지 번호 단락 앞에 빈 단락 1개 |

> footer1, footer3은 빈 파일. footer2만 실제 내용 보유.
> 꼬리말에는 페이지 번호(PAGE 필드)와 이미지 1개가 오른쪽 정렬로 배치됨.

## 7. 스타일 간 관계 요약

```
Normal (a4)
  폰트: 바탕체 / Times New Roman
  줄간격: 1.5배 / 문단뒤: 0pt
  └─ 1.번호매기기_내용     left=0.265cm
  └─ 가.번호매기기_내용    left=0.265cm, sz=12pt (명시)
  └─ (1)번호매기기_내용    (상속)
  └─ (가)번호매기기_내용   (상속)
```

> 한글/영문 크기 명시(sz=24, 12pt)는 `가.번호매기기_내용`에서만 확인됨.
> 나머지 본문 스타일은 Normal → 바탕체 12pt를 상속.
