# 녹취 환경 설치 (PC마다 최초 1회)

이 폴더는 다른 다섯과 달리 **PC마다 한 번씩 설치가 필요하다.** 파이썬 가상환경과 음성 모델이 수 GB이고 PC마다 따로 받아야 해서 OneDrive 동기화 대상에서 빼 두었기 때문이다.

**GPU 도 HuggingFace 토큰도 필요 없다.** 전사와 화자 분리 모두 CPU 에서 돈다.

## 1. 파이썬이 있는지 본다

명령 프롬프트에서:

```
python --version
```

버전이 나오면 된다. `python 을 찾을 수 없습니다` 가 나오면 [python.org](https://www.python.org/downloads/windows/) 에서 받아 설치하되, 설치 첫 화면의 **`Add python.exe to PATH` 를 반드시 체크**한다.

## 2. 설치를 돌린다

`5_녹취록` 폴더의 **`녹취록 환경설치.bat` 을 더블클릭**한다. 그게 전부다.

명령줄을 쓰고 싶으면:

```powershell
cd "$env:OneDrive\노동사건자동화\5_녹취록"
powershell -NoProfile -ExecutionPolicy Bypass -File .\setup.ps1
```

`.\setup.ps1` 로 바로 부르면 실행 정책이 Restricted 인 PC에서 막힌다(아래 '자주 겪는 것').

무엇이 설치되는가:

| | 어디에 | 크기 |
|---|---|---|
| 가상환경 + 패키지 | `%LOCALAPPDATA%\노동사건자동화\venv-녹취\` | 수백 MB |
| 전사 모델 (large-v3-turbo) | `%LOCALAPPDATA%\노동사건자동화\models\` | 약 1.6GB, 처음 전사할 때 받아짐 |
| 화자 분리 모델 | `5_녹취록\models\` | 35MB, 이미 들어 있음 |

**이 폴더 안에 `.venv` 를 만들지 않는다.** OneDrive 가 수 GB를 동기화하려 들고 PC 두 대가 서로를 깨뜨린다.

## 3. 검증 결과를 본다

설치가 끝나면 아래처럼 나온다. `ffmpeg (선택)` 을 뺀 다섯 줄이 전부 `예` 면 준비가 끝난 것이다.

```
  faster-whisper (전사)   : 예
  sherpa-onnx (화자분리)  : 예
  av / numpy              : 예
  화자 분리 모델          : 예
  ffmpeg (선택)           : 예
  화자 분리 가능          : 예
```

- **`faster-whisper` 가 `아니오`** 면 전사 자체가 안 된다. 설치 로그의 `[경고]` 를 먼저 본다.
- **`화자 분리 가능` 이 `아니오`** 면 전사는 되고 화자는 사용자가 직접 붙여야 한다. 급하면 그대로 써도 된다.
- **`ffmpeg` 은 선택이다.** 없어도 대개 돈다. 두려면 `winget install Gyan.FFmpeg`.

## 4. 첫 실행

```powershell
cd "$env:OneDrive\노동사건자동화\5_녹취록"
powershell -NoProfile -ExecutionPolicy Bypass -File .\녹취.ps1 {사건폴더명} -Speakers 2
```

음성파일은 `5_녹취록\사건\{사건폴더}\원본\` 에 넣는다.

**처음 실행할 때 전사 모델 1.6GB 를 내려받으므로 몇 분 더 걸린다.** 두 번째부터는 바로 시작한다.

**`-Speakers` 로 화자 수를 지정한다.** 통화는 2, 3자 면담은 3. 지정하지 않으면 화자를 과하게 쪼갠다.

## 자주 겪는 것

**`이 시스템에서 스크립트를 실행할 수 없으므로`** — PowerShell 실행 정책 때문이다. `.bat` 으로 실행하면 이 문제를 피한다. 명령줄에서 직접 돌릴 때에는 `.\setup.ps1`·`.\녹취.ps1` 처럼 바로 부르지 말고 위 2·4항처럼 `-ExecutionPolicy Bypass` 를 붙여 부른다:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\setup.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\녹취.ps1 {사건폴더명} -Speakers 2
```

**한글이 깨져 보인다** — `.ps1` 파일이 BOM 없이 저장된 경우다. Windows PowerShell 5.1 은 BOM 이 없으면 파일을 ANSI 로 읽어 한글 경로가 깨진다. 이 폴더의 `.ps1` 은 전부 UTF-8 BOM 으로 저장되어 있어야 한다.

**전사가 너무 느리다** — CPU 전사는 녹음 길이와 비슷하게 걸리는 것이 정상이다. 한 시간짜리면 한 시간, 화자 분리까지 하면 한 시간 십오 분가량이다. 내용만 빨리 보려면 `-Model small` 로 낮춘다.

**중간에 끊겼다** — 그때까지의 결과가 `.녹취.txt` 와 `.부분.jsonl` 에 남아 있다. 다시 돌리면 끝난 파일은 건너뛰고, 끊긴 파일은 처음부터 다시 전사하면서 이 두 파일을 새로 쓰므로, 끊긴 지점까지의 내용이 필요하면 다시 돌리기 전에 확인하거나 다른 이름으로 옮겨 둔다. 끝난 파일까지 다시 하려면 `-Force` 를 붙인다.
