# 2_판례검색

사용자가 던지는 질의에 관하여 LBOX에서 판례·결정례·행정해석을 검색하여 **찾은 것을 나열해 주는 것**이다. **검토의견서나 회신 초안을 작성하지 않는다.**

하이라이트 색은 **파랑**(`rgb(56,189,248)`, 팔레트 3번)이다.

## 1. 작업 순서

1. 첨부파일이 있으면 가장 먼저 읽는다. 계약서, 단체협약, 취업규칙, 사규 등 1차 자료의 실제 문언이 검색 결과보다 우선한다.
2. **질의를 쟁점 단위로 쪼갠다.** 하나의 질문에 둘 이상의 법적 쟁점이 섞여 있으면 나누어 각각 검색하고 각각 나열한다.
3. LBOX에서 검색한다 → `lbox-검색` 스킬
4. 필요하면 고용노동부 보도자료·지침·매뉴얼을 검색엔진으로 찾아 보탠다.
5. 나열한 판례·결정례·유권해석에 파란색 하이라이트를 남긴다 → `lbox-하이라이트` 스킬

## 2. 산출물

**산출물은 채팅 답변 하나이다.** 검토의견서·보고서 등 별도 서면이나 파일을 만들지 않는다. 사용자가 따로 요청하면 `사건/{주제}/`에 저장한다.

**다만 검색기록은 파일로 남긴다.** 답변 말미의 검색기록 표를 `공통/캐시/판례검색기록/{날짜}_{주제}.md` 에도 저장한다(`lbox-검색` 7항). 답변이 채팅에만 남으면 같은 질의를 다시 받았을 때 지난번 검색을 알 수 없어 그대로 되풀이하게 된다. 검색을 시작할 때에도 그 폴더와 `공통/캐시/법제처/`, `공통/판례기록/` 을 먼저 훑어 같은 쟁점을 다룬 기록이 있는지 본다.

## 3. 나열 방법

표로 나열하고 사건번호에 LBOX 링크를 건다.

**표의 열은 `사건 / 판시 요지 / 우리 사안에의 의미 / 방향`으로 한다.**

- **판시는 원문 그대로 한두 문장 인용한다.** 요약하거나 축약하지 않는다. 사용자가 그 문장을 보고 쓸지 말지를 판단하는 자리이므로, 실제 문구를 보여 주는 것이 이 작업의 핵심이다.
- 확정 여부는 사건 열에 괄호로 붙인다. 확정된 것과 확정되지 않은 것을 모두 표시한다.
- **사안의 차이를 반드시 적는다.** 기간의 길이, 규정이 취업규칙인지 단체협약인지 하위 내부규정인지, 공무원·교원 사안인지, 용어가 같은지 등이 달라지면 결론도 달라진다.
- 대법원 법리를 먼저 세우고 하급심을 뒤에 둔다. 같은 법리 안에서는 사안이 우리와 가까운 순으로 배열한다.
- 결정례·행정해석은 판례 표와 나누어 아래에 별도 표로 둔다.
- 쟁점 하나당 5~8건을 상한으로 한다. 같은 법리를 확인해 주는 판결을 여러 건 늘어놓지 말고 사안이 가장 가까운 것만 남긴다.
- 사용자가 이미 알고 있다고 밝힌 판례는 목록 맨 앞에 따로 모아 '이미 확인하신 것'으로 표시하고 중복 설명을 하지 않는다.

## 4. 반드시 지킬 것

**불리한 판례를 반드시 포함한다.** 결론이 갈리는 쟁점이면 양쪽을 모두 올리고 '방향' 열에 유리/불리를 한 단어로 적는다. 유리한 것만 모아 놓으면 조사가 아니라 변론이 된다. **이 규칙은 어떤 경우에도 예외를 두지 않는다.**

표 아래에 **찾지 못한 쟁점**과 **다음에 더 볼 만한 검색어**를 두세 줄로 덧붙인다. 검색을 다 하지 않은 채 '판례가 없다'고 쓰지 않는다. `lbox-검색` 스킬의 탭 단계를 어디까지 내려갔는지도 함께 밝힌다.

문장 종결은 단정형을 피한다. 다만 판시 내용을 그대로 옮기는 문장은 단정형으로 쓴다.

답변 말미에 몇 건에 하이라이트를 남겼는지 한 줄로 밝힌다.
