# 6_손해배상계산

대법원 「손해배상 등 계산프로그램」의 계산을 로컬에서 재현해 손해배상액 계산표를 만든다.
`C:\노동사건자동화` 의 여섯 번째 폴더이며, 슬래시 명령어는 저장소 루트에서 부른다.

## 설치 (PC마다 한 번)

    pip install -r requirements.txt
    python -m pytest tests\ -q      409건 통과 확인

## 노임표·생명표

`data/` 의 CSV 4종을 쓴다. **`노임표추출.bat` 을 더블클릭하면 끝난다**(설치 위치 탐색·32비트 전환·정규화·확인까지 자동). 막혔을 때는 `노임표-추출-절차.md` 를 본다.
대법원 프로그램이 깔린 PC에서 한 번만 뽑으면 OneDrive로 다른 PC에도 넘어간다.
없는 동안은 입력서의 `[노임단가 직접입력]` 표에 값을 적으면 계산은 된다.

## 쓰는 법 — 두 가지

### (a) 엑셀 입력서

`손배계산 시작.bat` 을 더블클릭하면 폴더가 만들어지고 감시가 시작된다.
작업 폴더는 이 폴더 자신이다(`watch.py --root` 기본값).

    00_양식\입력서.xlsx   ← 복사해서 노란 칸만 채운다
    01_입력\              ← 채운 입력서를 넣는다
    02_결과\              ← 계산표가 나온다
    03_보관\              ← 처리한 입력서가 옮겨진다
    99_오류\              ← 실패한 파일과 사유

한 번만 훑으려면 `python watch.py`, 계속 지켜보려면 `python watch.py --loop`.

### (b) 자료 폴더에서 읽기

`사건\<사건명>\` 에 진단서·판결문·급여명세서를 넣고, **저장소 루트**(`C:\노동사건자동화`)에서
Claude Code 를 띄운 뒤

    /손배계산 <사건명>

Claude 가 자료를 읽어 `사건.yaml` 초안을 만들고, **사람이 확인한 뒤** 엔진이 계산한다.
한글(.hwp)은 텍스트를 못 뽑으니 PDF 로 저장해서 넣는다.

기존 계산표나 상대방 별지를 검산하려면

    /손배검산 <파일경로>

### (c) 노동 금액 — 통상임금 재산정·퇴직금·연차수당 차액, 해고기간 임금, 지연손해금

저장소 루트에서 `/손배계산 <사건명 또는 사건 경로>` 를 부르면 Claude 가 자료를 읽어 `kind: labor` 사건.yaml 초안과
판정표(통상임금 해당 여부, 판례가 갈리는 옵션)를 만들고, **사람이 확인한 뒤** 엔진이 계산한다.
형식은 `cases\labor_sample.yaml`, `cases\labor_dismissal_sample.yaml`, 규칙·옵션은 `노동금액-계산기준.md`.

    python cli.py 사건\<사건명>\사건.yaml        사건.yaml 옆에 {사건번호}({성명})_노동금액계산표.xlsx

계산표는 요약(청구취지형 지연손해금 문구·대안 결과) / 모듈별 시트 / 지연손해금 / 소멸시효 / 경고 / 근거 시트로 나온다.

## 명령줄

    python cli.py 사건\<사건명>\사건.yaml -o 02_결과\계산표.xlsx
    python extract.py 사건\<사건명>
    python -m pytest tests\ -q

## 밖으로 내보내지 않는 것

`사건\`, `01_입력\`, `02_결과\`, `03_보관\`, `99_오류\`, `_추출.txt`.
의뢰인 실명·생년월일·상병내역이 들어간다. 루트의 `백업.ps1` 과 `.gitignore` 에서
제외되어 있다(이 폴더에는 별도 `.gitignore` 를 두지 않는다).

`C:\sut_extract`, `C:\sut_snapshot` 도 이 폴더로 들여오지 않는다. `data\` 의 정규화된
CSV 4종만 남긴다.

(여명단축, 한시장해, 조정 사건의 지연이자, 상속지분, 개호비 실사용).
