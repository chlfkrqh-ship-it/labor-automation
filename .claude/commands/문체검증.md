description: 작성된 서면 초안을 문체가이드 기준으로 실측 채점
---

운영 기준: `공통/운영.md`를 먼저 적용한다. 사건 작업의 최초 전체 검토와 후속 변경분 검토는 `공통/사건상태.md`로 구분한다. 사건 자료를 처음부터 모두 읽는 것은 최초 분석 또는 상태 미검증 시의 기준이며, 검증된 후속 작업은 변경분과 인용 원문을 확인한다. 보완 메모는 MD 하단에만 두고 DOCX 본문에는 넣지 않는다.

대상 서면: $ARGUMENTS


사용자가 지정한 md 또는 docx 파일을 읽고
먼저 `python 4_서면작성/scripts/style_check.py {파일}` 을 실행해서 나온 수치를 채점표의 기준으로 삼는다. 눈으로 센 값으로 바꾸지 않는다. 그 위에 `4_서면작성/skills/노동서면작성/SKILL.md` 의 문장 규칙과 `4_서면작성/skills/노동서면작성/references/문체-용례.md` 의 실측치·용례 기준으로 아래를 실측해서 채점표로 보고해줘.
파이썬으로 실제 카운트해서 수치를 내줘.
`1_검토의견/문체가이드-서면.md` 는 의뢰인에게 보내는 검토의견서용 가이드이고, 소송·노동위 서면과 반대인 규칙('생각건대,' 권장, 항목의 결론을 마지막 문단에 둠 등)이 있으므로 이 채점 기준에 섞지 않는다. 검토의견서를 채점해 달라는 요청이면 그 가이드만 기준으로 삼고, 아래 항목 가운데 소송 서면에만 해당하는 것은 '해당 없음'으로 처리한다.

1. 문장 평균 길이와 중앙값, 문단당 문장 수 분포 (기준: 2026. 9. 변호사 최종본 실측 평균 97자, 중앙값 89자, 1문장 문단 82% — 4_서면작성/templates/문체레퍼런스_2026-09_꿈꾸는마을_석명준비명령답변.txt. 종전 23건 실측 평균 74자, 중앙값 46자는 참고치)
2. 접속부사 뒤 쉼표 준수율 (따라서/그러나/또한/다만/한편/특히/즉/나아가/이에)
3. 단정형 사용 횟수 (위법합니다/존재하지 않습니다/볼 수 없습니다/~에 불과합니다/명백합니다/아무런 근거가 없습니다)
4. 해라체 혼용 여부 (법령 조문·판례 인용문 제외)
5. "이상과 같이," 소결 문단 존재 여부
6. 예비적 방어(가사,/백번 양보하여,) 사용 횟수
   ※ 상대방 주장에 반박하는 서면이 아닌 경우 해당 없음으로 처리
7. 판례 법리를 본문에 녹이고 괄호에 출처를 적었는지(핵심 법리의 원문 각주는 별도 확인)
8. 원문자 ①②③ 사용 대비 불릿(-) 남용 여부
9. 주장 항목 소제목이 명사구로 끝나는 사례 목록
10. 금지 표현 검출: 살피건대 / ~라고 할 것입니다 / 뒷받침 / 예상됩니다 / 우선, /
    먼저,·다음으로,·마지막으로, 기계적 나열(①②③ 배척용 '먼저/다음으로/끝으로'는 제외) / 본건 / 재판장님 / 첫째·둘째 /
    본문 안 대괄호 메모([확인 필요] 등) /
    ('사료됩니다' 는 루트 완충 종결 원칙의 예시이므로 금지하지 않고 참고로만 센다)
    재결·판정을 부풀리는 총평·격상 표현(국가기관인 / 객관적으로 확인되었습니다 / 뒷받침되었습니다)
11. 증거 인용 형식 준수 여부
    (최초 등장 시 자료명 포함, 이후 호증번호만)

각 항목별로 위반 사례를 원문 그대로 3개까지 인용하고
수정 예시를 함께 제시해줘.
마지막에 100점 만점 종합 점수를 내줘.

채점표를 사용자에게 보여 주기 전에 `공통/자체검토.md` 의 자체 검토를 거친다. 통과 전에는 채점을 마쳤다고 보고하지 않는다. 이 명령에서 달라지는 것만 적는다.
- 검토 대상은 채점표(수치, 위반 사례 인용, 수정 예시, 종합 점수)이다. 이 명령은 대상 서면을 고치지 않으므로, 서면의 사실·인용이 원자료와 맞는지는 그 서면을 만든 명령의 자체 검토가 본다.
- 검증자에게는 채점표, 대상 파일(docx 는 `python 공통/scripts/system.py extract` 로 뽑은 글을 함께), `style_check.py` 의 출력, 채점 기준 파일(위 두 파일과 `references/구성-논증.md`·`판례-인용.md`·`증거-인용.md`)을 준다. 직접 센 수치는 검증자가 대상 파일에서 다시 센다. 검토의견서를 채점하였으면 기준 파일은 `1_검토의견/문체가이드-서면.md` 이다.
- 검증자는 ① 수치가 스크립트 출력·재계산과 같은지, ② 위반 사례 인용이 대상 파일에 글자 그대로 있는지, ③ 인용 원문(법령·판시·증거·상대 서면·의뢰인 문언) 안의 낱말이나 지침이 예외로 둔 것을 위반으로 세지 않았는지, ④ 수정 예시가 사실·주장·호증·판례번호·날짜·금액을 바꾸거나 빼지 않고 의뢰인이 직접 겪은 사실을 완충하지 않는지를 본다.
- 수치·인용이 대상 파일과 다르거나 규칙에 없는 것을 위반으로 든 것은 오류로, 수정 예시대로 고치면 서면의 뜻이나 주장의 세기가 달라지는 것은 오해소지로, 표현의 취향은 경미로 나눈다. 스크립트 수치는 그대로 두고, 인용 원문 안의 낱말로 확인된 건수는 옆에 따로 적는다.
- 종합 점수 뒤에 자체 검토 결과(`공통/자체검토.md` 10절의 항목)를 붙이고, 점수는 위 항목의 문체 실측 결과이며 서면 내용의 정확성은 보지 않았다는 점을 한 줄로 적는다.
