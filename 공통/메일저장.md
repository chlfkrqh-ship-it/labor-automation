# 메일 저장 (Power Automate → 원드라이브 과거메일함)

받은 아웃룩 메일을 원드라이브에 .eml 로 저장해 두고, 검토의견 등에서 의뢰인 메일을 지목하면 AI 가 바로 찾아 읽는다.
저장소(노동사건자동화) 바깥이므로 git 에 올라가지 않는다.

```
OneDrive - 법무법인 평안\
├─ 과거메일함\              ← 찾기 대상(하위 폴더 전부). 예전부터 있던 메일은 그대로 둔다
│  └─ 자동저장\             ← Power Automate 가 새 메일을 저장하는 곳. 오래된 것은 여기서만 지운다
└─ 노동사건자동화\
```

## 찾아 읽기 (AI 가 한다)

```
python -B 공통/scripts/mail.py find --from 김철수 --since 2026-10-01
python -B 공통/scripts/mail.py open "<eml 경로>" --to "1_검토의견/사건/{의뢰인}_{검토내용}"
```

`open` 은 사건 폴더에 `메일/{받은 일시}_{제목}/` 을 만들어 본문(`본문.txt`)과 첨부를 둔다. 첨부는 그 자리에서 읽는다
(PDF·docx 는 `공통/scripts/system.py extract`).

## 흐름 1 — 받은 메일을 eml 로 저장 (한 번만 만든다)

make.powerautomate.com 에 회사 계정으로 들어가 **만들기 → 자동화된 클라우드 흐름**.

1. 트리거: Office 365 Outlook **새 메일이 도착하는 경우 (V3)** — 폴더 `받은 편지함`.
2. 동작: Office 365 Outlook **전자 메일 내보내기 (V2)** — 메시지 ID 에 트리거의 `메시지 ID`.
3. 동작: OneDrive for Business **파일 만들기**
   - 폴더 경로: `/과거메일함/자동저장`
   - 파일 이름(식):
     ```
     concat(convertFromUtc(triggerOutputs()?['body/receivedDateTime'],'Korea Standard Time','yyyyMMdd-HHmmss'),'_',take(replace(replace(replace(replace(replace(replace(replace(replace(replace(coalesce(triggerOutputs()?['body/subject'],'제목없음'),'\','_'),'/','_'),':','_'),'*','_'),'?','_'),'"','_'),'<','_'),'>','_'),'|','_'),60),'.eml')
     ```
   - 파일 콘텐츠: 2단계의 `본문`(내보낸 메일 전체. 첨부가 들어 있다)
4. 저장하고, 시험 메일을 한 통 보내 `자동저장` 에 .eml 이 생기는지 본다.

## 흐름 2 — 오래된 메일 지우기 (한 번만 만든다)

**만들기 → 예약된 클라우드 흐름**, 매일 1회(오전 6시).

1. 동작: OneDrive for Business **폴더의 파일 나열** — 폴더 `/과거메일함/자동저장`.
2. **각각에 적용**(1단계의 `value`) 안에 **조건**: 식 `less(item()?['LastModified'], addDays(utcNow(), -90))` 이 `true` 이면
3. OneDrive for Business **파일 삭제** — 파일 `item()?['Id']`.

보존 기간은 90일이다(식의 `-90` 을 바꾸면 달라진다). 지운 파일은 원드라이브 휴지통에 한동안 남는다.
`자동저장` 밖(과거메일함의 예전 메일)은 이 흐름이 건드리지 않는다.

## 주의

- 메일 내용(본문·첨부)은 사건 폴더 밖, 곧 git 에 올라가는 곳(판례기록·지침 등)에 옮겨 적지 않는다.
- 저장이 멈추면(계정 암호 변경 등) Power Automate 의 **내 흐름**에서 흐름 1 의 실행 기록을 본다.
