# 노동 업무 실행

루트 `AGENTS.md`와 `공통/운영.md`를 적용한다. 사용자의 요청에서 명령어와 사건·라운드를 확인하고 `공통/명령어/{명령어}.md` 하나만 읽는다. 슬래시 없이 자연어로 요청한 경우에도 해당 업무를 연결한다. 애매한 범위만 사용자에게 확인한다.

- 사건 작업은 `공통/사건상태.md`에 따라 시작한다.
- `/결과비교`는 `공통/결과비교.md`를 읽는다. 기존 두 결과를 비교하는 요청이면 새 모델 작업을 시작하지 않는다.
- LBOX가 필요할 때만 검색·하이라이트 스킬과 `공통/브라우저.md`를 읽는다.
- 문서 생성 시에만 제품의 문서 도구 지침을 추가로 읽는다. 기존 스크립트·양식을 사용하고 실제 렌더로 확인한다.
- 자료 경로가 메시지에서 `4\_서면작성`처럼 표시되면 실제 존재하는 `4_서면작성`과 대조해 해석한다.
- 이 스킬은 모델을 변경하거나 하위 에이전트를 자동 호출하지 않는다.
