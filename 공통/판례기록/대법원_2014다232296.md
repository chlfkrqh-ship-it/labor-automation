# 대법원 2014다232296
- URL: https://lbox.kr/case/대법원/2014다232296
- 쟁점: 업무상 재해 휴업기간의 출근율 산정, 사용연도에 전혀 출근하지 못한 경우 연차휴가수당 청구 가부와 이를 제한하는 단협·취업규칙의 효력
- 판시 요지: 업무상 재해 휴업기간은 장단 불문, 1년 전체라도 소정근로일수와 출근일수에 모두 포함. 이미 부여받은 연차휴가는 사용연도에 전혀 출근하지 못했어도 수당 청구 가능하고 이를 제한하는 단협·취업규칙은 무효.
- 인용할 문장(원문 그대로):
  - "그러므로 근로자가 업무상 재해로 휴업한 기간은 장단(장단)을 불문하고 소정근로일수와 출근일수에 모두 포함시켜 출근율을 계산하여야 한다. 설령 그 기간이 1년 전체에 걸치거나 소정근로일수 전부를 차지한다고 하더라도, 이와 달리 볼 아무런 근거나 이유가 없다."
  - "따라서 근로자가 업무상 재해 등의 사정으로 말미암아 연차휴가를 사용할 해당 연도에 전혀 출근하지 못한 경우라 하더라도, 이미 부여받은 연차휴가를 사용하지 않은 데 따른 연차휴가수당은 청구할 수 있다."
- 확정 여부와 상·하위 판결: 연차휴가수당 부분 파기환송(창원지법 2012가합6820 → 부산고법(창원) 2013나21461 → 대법원 2014다232296 → 부산고법(창원) 2017나21100 → 대법원 2017다264416 상고기각, 이후 재심 2018재나30 → 대법원 2019다236927 상고기각)
- 따름 판례: LBOX 표시 123건(목록 미열람). LBOX가 "대법원-97다5015 판례에 의해 변경된 대법원-92다24509 판례를 참조한 판례" 경고를 표시함. 92다24509 원문 확인 결과 97다5015(전원합의체, 퇴직금)로 변경된 부분은 퇴직월 급여의 평균임금 산입 쟁점으로 보이며, 이 판결이 인용한 '기준 미달 근로조건 무효' 부분과는 다른 쟁점임(97다5015 판시 전문은 미열람).
- 그 법리를 인정한 근거와 사안 전제: 2000. 12.경~2012. 7.경 업무상 재해로 전혀 출근하지 못한 근로자, 2009~2011년 연차휴가수당 청구, 단협·취업규칙에 1년 전체 미출근 시 미부여 규정.
- 확인한 날짜와 확인한 사건: 2026-09-15 노동금액 엔진 조사(annual_leave)
