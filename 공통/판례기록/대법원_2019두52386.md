# 대법원 2019두52386
- URL: https://lbox.kr/case/대법원/2019두52386
- 쟁점: 구제신청 중 정년·계약기간 만료로 원직복직이 불가능해진 경우 재심판정 취소소송의 소의 이익(전원합의체, 종전 판례 변경)
- 판시 요지: 해고기간 중 임금 상당액을 지급받을 필요가 있으면 임금 상당액 구제명령을 받을 이익이 유지되어 소의 이익 인정. 제30조 제3항 금품지급명령 신청의 경우도 같음. 95누12347 등 종전 판결 변경.
- 인용할 문장(원문 그대로):
  - "근로자가 부당해고 구제신청을 하여 해고의 효력을 다투던 중 정년에 이르거나 근로계약기간이 만료하는 등의 사유로 원직에 복직하는 것이 불가능하게 된 경우에도 해고기간 중의 임금 상당액을 지급받을 필요가 있다면 임금 상당액 지급의 구제명령을 받을 이익이 유지되므로 구제신청을 기각한 중앙노동위원회의 재심판정을 다툴 소의 이익이 있다고 보아야 한다."
- 확정 여부와 상·하위 판결: 확정. 서울행정법원 2017구합6235 → 서울고법 2019누30487 → 대법원 2020. 2. 20. 전원합의체 파기자판(제1심 취소·환송) → 서울행정법원 2020구합56179 → 서울고법 2020누48439 → 대법원 2021두33487 상고기각
- 따름 판례: LBOX 표시 83건(목록 미열람)
- 그 법리를 인정한 근거와 사안 전제: 행정소송 소의 이익에 관한 판결이며 민사상 임금 청구의 종기(정년일·만료일)를 직접 판시한 것은 아님. 이후 근로기준법 제30조 제4항(2021. 5. 18. 신설)으로 입법화.
- 확인한 날짜와 확인한 사건: 2026-09-15 노동금액 엔진 조사(dismissal_wage)
