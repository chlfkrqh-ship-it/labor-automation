# 판례 기록

사건을 넘나들며 재사용하는 판례 메모를 모은다. 파일 하나에 판례 하나이고, 이름은 `{법원}_{사건번호}.md` 이다(예: `대법원_2010두20362.md`). 법원명은 LBOX URL과 같게 공백 없이 붙여 쓴다.

작성 형식과 사용 규칙은 `.claude/skills/lbox-검색/SKILL.md` 의 '6. 검색 기록과 판례 기록'에 있다.

**이 폴더는 탐색용이고 인용의 최종 검증을 대체하지 않는다.** 여기 적힌 문장이라도 서면·검토의견에 인용할 때에는 LBOX 원문에서 다시 확인하고, 그 자리에서 이번 작업 색으로 하이라이트를 새로 칠한다. 기록만 보고 인용하면 하이라이트가 남지 않아 사용자가 이번 작업에서 그 판례를 썼는지 확인할 수 없게 된다. 기록이 있다고 해서 검색 범위를 줄이지 않는다.

`공통/캐시/` 와 달리 재생성되지 않는 자료이므로 시스템 백업에 포함된다. 사건별 검색 이력은 각 사건의 `작업/검색기록.md` 에 남기고 여기에 두지 않는다.
