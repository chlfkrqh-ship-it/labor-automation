# 대법원 2019다261084
- URL: https://lbox.kr/case/대법원/2019다261084
- 쟁점: 복지포인트의 임금성, 단협상 중복 가산율(각 50%)과 법정 통상임금의 조합, 휴일·야간 실제 중복 범위 심리
- 판시 요지: 통상임금만 법정 기준으로 넓히고 가산율은 단협 조항을 적용하는 것은 취사선택으로 구 근로기준법 제15조 취지에 위배. 통상임금 범위와 가산율 모두 법정 기준으로, 실제 중복 범위를 심리해 정당한 금액을 산정하고 기지급액과 전체 비교해 차액만.
- 인용할 문장(원문 그대로):
  - "통상임금의 범위뿐 아니라 가산율 역시 근로기준법에서 정한 기준을 적용하였어야 하고, 휴일근로와 야간근로 등이 실제 중복되는 구체적인 범위를 심리하여 원고별로 휴일근로수당 등의 정당한 금액을 산정한 후, 이를 원고들에게 기지급된 휴일근로수당 등과 전체적으로 비교하여 그 차액의 지급만을 명하였어야 한다."
- 확정 여부와 상·하위 판결: 울산지법 2014가합1115 → 부산고법 2018나57103 → 대법원 2019다261084(파기환송) → 부산고법 2019나58516 강제조정. LBOX '확정'.
- 따름 판례: LBOX 표시 65건(목록 미열람)
- 그 법리를 인정한 근거와 사안 전제: 울산광역시(지자체) 근로자, 단협 '연장·야간·휴일노동이 중복될 때 통상임금의 50%를 각각 가산', 원심이 휴일근로시간 전부에 200% 적용. 휴일근로 중 야간 해당 시간 구분 자료가 없었음. 구법 사안.
- 확인한 날짜와 확인한 사건: 2026-09-15 노동금액 엔진 조사(overtime); 2026-09-17 SR노조 통상임금 상고심(대법원 2026다207222) 판례검색
